# Rollover Run

모바일 자이로센서로 좌우 롤 입력을 받아 주황 적 3종은 피하고 청록 계열 코어 3종은 수집하는 `three.js` 기반 HTML 게임입니다.

## 실행

```bash
uv run python -m http.server 4173
```

그다음 브라우저에서 `http://127.0.0.1:4173` 를 엽니다.

## 조작

- 모바일: `센서로 시작` 후 휴대폰을 좌우로 기울여 조작
- 수동 터치: `터치로 시작` 후 화면 좌우 드래그
- 재중심: `Recenter` 버튼

## 참고

- iPhone Safari 는 자이로 사용 전에 권한 팝업이 뜹니다.
- 휴대폰에서 `http://192.168.x.x:4173` 같은 일반 HTTP 주소로 열면 자이로센서가 차단될 수 있습니다.
- 실제 센서 입력은 보통 `HTTPS` 또는 `localhost` 환경에서 가장 안정적으로 동작합니다.
- 폰 실기 테스트는 정적 호스팅으로 `HTTPS` 배포하거나, `HTTPS` 터널을 통해 여는 방식이 가장 간단합니다.
